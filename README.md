# Go-WebRTC Session Manager

## Краткое описание
Микросервисная система для управления сессиями WebRTC на базе Go и PostgreSQL, развернутая в кластере Kubernetes (MicroK8s). Проект реализует высокопроизводительный HTTP-API для регистрации пользовательских сессий с использованием MetalLB для внешнего доступа.

## Архитектура и компоненты

### Backend (Golang)
Легковесный сервис, использующий фреймворк `fasthttp` для достижения минимальных задержек. 
*   **Роутинг:** Управление жизненным циклом сессий (эндпоинт `/session/start`).
*   **Логика:** Бизнес-логика вынесена в изолированный слой `internal/service`.

### Database (PostgreSQL 13)
Реляционное хранилище для данных о сессиях (таблица `sessions`). 
*   **Инициализация:** Структура БД создается автоматически при первом запуске через `ConfigMap` и SQL-скрипты в директории `docker-entrypoint-initdb.d`.

### Инфраструктура (Kubernetes / MicroK8s)
*   **Deployment:** Обеспечивает отказоустойчивость и декларативное управление состоянием подов.
*   **Networking:** Использование **MetalLB** для предоставления выделенного `External-IP` в локальной сети.
*   **Configuration:** Безопасное разделение общих настроек (`ConfigMap`) и учетных данных (`Secrets`).

## Ключевые особенности
*   **Modern Tooling:** Контейнеризация без демона Docker с использованием **Podman**.
*   **Auto-provisioning:** Автоматическая инициализация схемы базы данных при деплое.
*   **Performance:** Минимальное потребление ресурсов за счет компиляции Go в бинарный файл внутри компактного Alpine-образа.
*   **DevOps Friendly:** Оптимизированный локальный цикл разработки с прямым импортом образов в `containerd` кластера MicroK8s.
